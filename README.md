# 🎮 Java Terminal Adventure Game

A simple text-based RPG game built in Java.

## 🚀 Features
- Explore and fight random monsters
- Health and potion system
- Gold collection
- Simple battle mechanics
- Console-based interaction

## 🛠 Technologies Used
- Java
- OOP Concepts
- Random class
- Scanner for user input

## ▶ How to Run

1. Clone the repository
2. Compile:s
   javac Main.java
3. Run:
   java Main

This is my first Java project to practice:
